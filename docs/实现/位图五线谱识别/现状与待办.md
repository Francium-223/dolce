## 调号兜底：竖笔 + 粗杠原型（未接进识别器）

现有判据独唱谱调号 43/44，仍错的是《耶和华是我的牧者》（扫描件，粗体升号两两粘连、贴着谱号，谱号盒吞了 F♯）。

原型 `../dev/scripts/key-stems-proto.py` 照 Audiveris 的路子：不看连通块，谱号主体右边到拍号/第一个音之间逐列找竖直连续墨
（容 2px 断口、≥2 格；高过 3.6 格的是拍号或符干，到此为止），两根相距 0.15~0.8 格、中列有两道厚 ≥0.25 格横杠 = 升号，
单根竖笔右下有墨 = 降号，全页取众数。独立判对 31/43，**能判对耶和华**（网纹空心粗杠、细实竖笔）；
错在降号（细笔画断竖笔：所信有根基、万福泉源歌）与把谱号/音符竖笔当记号（主使我喜乐、来敬拜荣耀王、有一位神）。

**下一步**：只在现有判据与全页表决都拿不出结论时（各行不一致、没有两行相同）用它投票；先接升号那一半（粗杠判据稳）；
调号区起点按谱号正常宽度（约 2.4 格）算，不按盒右缘。

同 x 符头对 347 组里 45 组没折进同一枚和弦（25 组是左手八度）。它们在 `initChords` 末尾的 `rest` 循环里才建，

## 符杠按组判

多层连桁里上面那条杠的下方是另一条杠，逐条按「挂着符干」判会杀真杠。要按符干收假杠，得把一组连桁当一个四边形
（外缘才有符干）——结构改写。注意过检的杠有承重作用（[符干符杠符尾](符干符杠符尾.md)「符杠的检出量」）。
