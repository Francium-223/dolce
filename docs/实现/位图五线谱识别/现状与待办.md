## 独唱谱其余（44 首 GT，音符 91.59%、时值 89.36%，小节数、调号、拍号全对 44/44）

判据与试过撤掉的做法见[简谱混排与独唱谱补认](简谱混排与独唱谱补认.md)；逐首定位小节切错用
`staff-measure-all.mjs --bars`（见[度量与跨系统连接](度量与跨系统连接.md)「排查一处错」）。

- **我一生要赞美你多出音符**（识别 158 / GT 134）：谱表上方和弦字母「G」的内腔被收成二分头（读成 B5，与下面的 D4 凑成和弦），
  第四行「喜」字被收成两个实心头（D3、B2）；几个圈厚的二分头内腔小、读成实心（时值 76.9%）。
- **C 拍号不稳**：我一生要赞美你的 C 被谱线切碎（谱头区碎成三四块），凑巧认对。
- **万古磐石歌时值 80.5%**：同干和弦成员时值不一致（D4 附点四分、同干 F4 附点八分）；
  一处十六分双钩的窗口里另有竖墨把右缘撑平，两条钩判据都认不出。
- **所信有根基**（音符 81.4%）：歌词字的横笔被当成加线，字的一笔归到谱表下方成了低音（第一行「确」读成 C3）；八分符尾有的没挂上干。
- **「头 + 干」摘头偏一格**：主我敬拜你一个带尾 F4 读成 E4（音符 90.2%）。按墨重心复核音位伤了向主唱新歌（90.3 → 82.0%），撤了。
- **时值偏低**（合计 89.36%）：有一位神 75.8%、所信有根基 78.8%、父恩广大 80.7%、我灵镇静 80.1%、万古磐石歌 81.6%、平安夜歌 81.7%。
  剩下最多的一类是空心二分头读成实心（二分读成四分 70 处，分散在耶和华、所信有根基、父恩广大、高举主大能等）。
  试过「同一根干上有空心头、实心头又没杠没尾就改成空心的时值」（加多数条件）：净 +0.13，救主降生 −1.5、齐来崇拜 −0.8——
  空心头的误认（二度挤在一起的实心头认出「内腔」）和漏认一样多，同干统一分不出哪边对，撤了。要从空心头判据本身下手。
- **降号还没接竖笔判据**：细笔画降号的竖笔断开（所信有根基、万福泉源歌），原型判不稳；等有降号曲调号认错时再接。
- **音符未到 90%**：耶和华是我的牧者 87.5%、齐来谢主歌 79.9%、所信有根基 81.4%、
  我灵镇静 83.7%（和弦漏音）、父恩广大 88.0%、晨曦破晓 88.9%。

## 合唱谱扫描件的符头召回

漏音是扫描件最大的一类，吸错一格 / 差一线也多半是它的下游。`raster-gap.mjs` 量出剩下的漏音**过半焊在大于 6×4 格的团里**
（符杠 + 符干 + 几个头），在闸门上让步的几条都已证伪（[符头与加线](符头与加线.md)「试过撤掉的」）。
下一步从更前面找：去谱线只看上下邻墨，分不开「谱线」与「落在擦除带里的扁笔画」，头被啃窄。
可逐符头比对破碎干净版与扫描版的 blob 归属，找「干净版认成符头、扫描版认成别的」那一批。

全局指派 + 谱面标签之后，破碎的槽位与人工映射只差 4 行系统（仍归槽位 2/3，应为 0/1）。
那一档谱面没印标签（裁图核对过），组内传播无从传起；音域已证伪（[度量与跨系统连接](度量与跨系统连接.md)）。有新信号再动。

## 独头和弦的建立时机

同 x 符头对 347 组里 45 组没折进同一枚和弦（25 组是左手八度）。它们在 `initChords` 末尾的 `rest` 循环里才建，
合并循环见不到；`ORPHAN_STEP` 5 → 9、把断干合并扩到无干那一档都一分不动，`STEM_JOIN_X` 放宽更差。
要先理清独头和弦的建立与合并顺序——结构改动。

## 符杠按组判

多层连桁里上面那条杠的下方是另一条杠，逐条按「挂着符干」判会杀真杠。要按符干收假杠，得把一组连桁当一个四边形
（外缘才有符干）——结构改写。注意过检的杠有承重作用（[符干符杠符尾](符干符杠符尾.md)「符杠的检出量」）。
