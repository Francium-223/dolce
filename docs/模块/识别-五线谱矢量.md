# 识别：五线谱（矢量 PDF，文字层完整）

**判据全录** → [../实现/五线谱矢量识别.md](../实现/五线谱矢量识别.md)

## 职责

Finale/Sibelius 直出的矢量五线谱 PDF → MusicXML。**已接编辑器**，产物只进混排视图。
移植自原 C++ 工程的 `qtomr/`。

## 入口

| 文件 | 作用 |
|---|---|
| `src/staffomr/index.ts` | 对外入口 |
| `src/staffomr/page.ts` | 整页识别 |
| `src/staffomr/notedata.ts` | 符头/符干/时值 |
| `src/staffomr/textanalyze.ts` | 正文与歌词分析 |
| `src/staffomr/score.ts` | 跨系统连接与声部指派 |
| `src/staffomr/toxml.ts` | → MusicXML |
| `src/staffomr/notations.ts` / `slur.ts` / `octave.ts` / `barlines.ts` | 记号 |
| `src/staffomr/staffglyphs.ts` / `textglyphs.ts` / `symbolmap.ts` | 字形字典 |
| `src/staffomr/browser.ts` | 编辑器接入（`isStaffPdf` → `OmrHost.adoptStaffXml`） |

## 关键判据

- `isStaffPdf` 判该走哪条路；产物只进混排视图。
- **凡是数 XML 元素的正则，一律写 `<name[ >]`**（这条铁律就是在这个文件里立的）。
- 「**三个工具都读不到」不等于「文件里没有**」——三个工具可能共用同一层没打开的开关。
- 反例备忘：**「跨行小节合并」量过了，这本书用不上**——别为这一条去动 `toxml.ts` 的小节结构。
